# 市場ページの整理と再設計のプロンプト

市場の画面(ホーム・なぜ動いたか・需給と戦略)を整理し直す時に、そのまま使う指示です。
データや機能が増えるたびに、この指示で整理を繰り返します。

---

## 役割
あなたは金融メディアの情報設計者兼UIデザイナーです。毎朝この画面を開く個人投資家(初心者〜上級者)が、
**最初の1画面で「何が起きたか・なぜか・どうするか」を掴み、必要な人だけが根拠と詳細へ降りていける**ように、
既存のデータを1つも捨てずに並べ替え、まとめ、見た目を整えます。

## 原則
1. **結論が先**: 各ページの最初のカードに、そのページの答えを置く。「何が起きた → なぜ → どうする」の順。
2. **1つの情報は1か所**: 同じ結論・同じ数字を別のカードで繰り返さない。繰り返しはリンクに替える。
3. **3つの層**: 要点(常に見える) → 根拠(タブで切り替え) → 詳細(折りたたみ)。
   AIの各役割の全文、データの自動判定、答え合わせ、ニュースの一覧、データの確認は「詳細」に置く。
4. **同じ種類はタブでまとめる**: 縦に並んだ同じ種類のカード(セクター・寄与・銘柄・お金の流れ・市場一覧、
   オプション・出来高・建玉・投資部門別・日程)は1枚のカードのタブにする。開いているタブ以外は描かない。
5. **日付と出所をそろえる**: ホームとなぜ動いたかで、違う日付の結論を並べない。新しい方(深掘り分析)を優先する。
6. **見出しは問いの形**: 「何が起きたか」「なぜ」「どうするか」「この先」など、読む理由がわかる見出しにする。
7. **数字は小さな数字の帯にまとめる**: 主要な指数・金利・VIX・為替の水準と前日比を、要点のすぐ下に横並びで出す。
8. **色の意味は3つだけ**: 上昇=緑、下落=赤、注意=砂色。強調のための色を増やさない。
9. **スマホ(幅390px)でも**、要点が1画面目に入り、表が横にはみ出さない。

## 画面全体の構成(情報の種類で分ける。2026-11-28)
1つの画面には1種類の情報だけを置く。混ぜると「どこに何があるか」が分からなくなる。
- **今日**(ホーム): 今日の要点(何が起きたか=数字つき / なぜ=根本の原因1文 / どうするか=規則の判定)→ 今日の答え(画面ごとに1行)→ S&P 500の推移
- **データ**(事実・AIを入れない数字): 価格の動き(セクター・指数を動かした銘柄・大型株・お金の流れ・金利為替世界。期間1日/5日/20日)/ 需給(オプション・出来高・大口の持ち高・日本の主体別)/ 長い推移(指標とチャートへ)/ データの確認
- **なぜ動いたか**(解釈): 今日の見出しと何が起きたか / 原因を根本までたどる(因果の段・動きの型)/ 市場ごとの説明(米国・日本・強気と弱気・需給の見方)/ 業種ごとの理由 / 詳しく(アナリスト会議・自動判定・学べること・ニュース)
- **戦略**(判断): 規則の判定 / 今の戦い方と損切りの価格 / 指数ごとの規則と計算 / 詳しく(規則を選んだ理由・売買戦略の担当)
- **この先**(先行き): 次の5営業日の予想と答え合わせの成績 / 見通し(短期・中期・変わる条件・注目)/ 近い日程 / 7つの視点の見立て(タブ: 今の位置・弱気と強気・採点・過熱チェック・シナリオ・変わる条件・日本株)
- 記録と答え合わせ: 分析の記録(memory.py。1取引日1件、続いている構造・テーマの移り変わり・主導役の持続・前回からの変化・型ごとの成績・記録の一覧)と予想の採点。なぜ動いたかには「これまでとのつながり」(チーフの continuity と前回からの変化)を置く
- 答え合わせ・指標とチャートは、この先・データの下位の画面。学ぶ・用語集・質問はメニューの「わからない時に」
- 画面下のボタン: 今日・なぜ | データ・戦略・この先 と、質問(＋)
- 各画面の見出しの下に「この画面の問い」、先頭に「このページの中身」(欄の目次)
- 同じ文・同じ数字は1か所。ほかの画面からはリンクにする(例: 業種の数字はデータ、業種の理由はなぜ動いたか)
- 長いAIの段落は文ごとの箇条書きにする(文は変えない)
- データの需給の各タブの下に「このデータから読めること」と、プロのアナリスト(だれが・なぜ)・プロのトレーダー(数日〜数週の売買)・プロの投資家(数か月〜数年の資産配分)の意見を置く。毎朝のAIの文(数字は照合済み)を優先し、無い時は数字から規則で組み立てた文を出す。数字の表とは枠を分け、解釈であることがわかるようにする

## 手順(1回で終わらせず、重ねる)
1. **棚卸し**: 各ページのカードを上から順に書き出し、「要点・根拠・詳細」のどれか、ほかと重複しているかを付ける。
2. **並べ替え**: 原則に沿って新しい順番とタブ・折りたたみの割り当てを決める。何も捨てていないことを確かめる。
3. **実装**: 共通の部品(数字の帯・タブ・折りたたみ)を作り、各ページをそれで組み直す。
4. **撮影して見直す**: 幅1280pxと390pxで撮影し、次の基準で点検する。満たさない点があれば2に戻る。
   - 最初の1画面に、結論・主要な数字・どうするかがある
   - 既定の表示で、なぜ動いたかのページの高さが半分以下、需給と戦略が6割以下になっている
   - 同じ文が2か所に出ていない。ホームと分析の日付が食い違っていない
   - 元の情報がすべて、タブか折りたたみのどこかから見られる
5. **試験**: Pythonの試験と `node learn/tests/check.js` がすべて通る。

## 完成の形

### なぜ動いたか
1. 今日の要点: 見出し / 数字の帯 / 何が起きたか(米・日の方向と1文) / なぜ(根本の原因の1文) / どうするか(規則の判定の文と需給へのリンク)
2. 原因を根本までたどる: 根本の原因の連鎖 + 動きの型(割合の帯。証拠は開くと見える)
3. 市場ごとの説明: タブ「米国」「日本」「強気と弱気」
4. データで確かめる: 期間(1日・5日・20日) + タブ「セクター」「指数を動かした銘柄」「大きく動いた大型株」「お金の流れ」「金利・為替・世界」
5. この先: 見通し(短期・中期) / 見解が変わる条件 / 注目するもの
6. 詳しく見る(折りたたみ): アナリスト会議 / データの自動判定 / 過去の見解の答え合わせ / 今日の相場から学べること / 分析に使ったニュース / データの確認

### 需給と戦略
1. 今日の要点: 需給の結論 / 規則の判定の文 / 指数ごとの投資比率・注意の度合い・売買の大きさの小さな札
2. 今の戦い方: 方針 / 機能しやすい行動・避ける行動 / 損切りと考えを変える価格
3. 指数ごとの規則と計算: タブ「S&P 500」「日経平均」(規則・価格帯・売買の大きさの計算。過去の成績は折りたたみ)
4. 需給のデータ: タブ「オプション」「出来高」「大口の持ち高」「日本の主体別」「日程」
5. 詳しく見る(折りたたみ): この規則を選んだ理由 / 担当アナリストの分析

### ホーム
深掘り分析の方が新しい時は、上部の見出しと「今日の相場」のカードを深掘り分析の要点(見出し・数字の帯・根本の原因)に替える。

### すべての画面の上部
電光掲示板(東証アローズの円形の表示のような帯)に、その日の取得データ(指数・金利・為替・商品・世界の指数・大きく動いた大型株・セクターの上位と下位)を流す。
値は深掘り分析と同じ日付のものを使い、ほかの画面と食い違わせない。マウスを乗せると止まり、動きを減らす設定の人には流さない。
