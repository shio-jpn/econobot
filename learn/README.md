# 株トレ道場

実績ある投資家の原則から、日本株・米国株を基礎から応用まで学ぶための学習アプリです。
ビルド不要の静的サイトで、`learn/index.html` をブラウザで開くだけで動きます
(GitHub Pages では `https://<ユーザー名>.github.io/econobot/learn/`)。

## もとにした依頼と、設計に使ったプロンプト

> 株で高いパフォーマンスを残し副業として成り立たせるために、イチから学べるアプリを作る。
> 米国株・日本株の両方。金利やCPIなどのマクロ、チャートの形、出来高、インジケーターまで。
> 学び方は最適なものを選ぶ。検索機能は必須。一般人の情報ではなく、片山氏・テスタ氏・
> 海外の実績あるトレーダーを参考にする。

これを次の仕様に落として実装しました。

1. **対象と目的**: 本業を持つ初心者が、日本株・米国株で「損小利大を繰り返せる」状態になること。
2. **情報源の基準**: 長年の実績が本人の著書・公表・報道で確認できる投資家(片山晃、テスタ、cis、BNF、
   オニール、ミネルヴィニ、クラマギ、ワインスタイン、リバモア、ドラッケンミラー、P・T・ジョーンズ、
   リンチ、スィコータ)に限り、手法の違いを超えて共通する原則を軸にする。人物ごとに出典を明記し、
   数字は「報じられている」「本人が公表」と区別して書く。
3. **学び方**: 段階別カリキュラム(読む) → 各レッスン末の確認問題(思い出す) → 間隔反復(1→3→7→16→35日)
   → チャート当てクイズとツール(使う)。読み返しより検索練習と分散学習のほうが定着する、という
   学習研究の知見に基づく。
4. **内容**: 株の基礎 / マクロ経済 / 企業分析 / チャート / リスク管理 / 戦略 / メンタルと運用。
   マクロは「起きたこと → 連鎖 → 動きやすい方向 → ただし」の因果マップでも引けるようにする。
5. **検索(必須)**: 用語・レッスン・因果マップ・チャート・人物を横断。別名(消費者物価指数→CPI)、
   全角・ひらがな・小文字の表記ゆれに対応し、関連語をたどれる。
6. **誠実さ**: 利益を保証しない。相場が教科書どおりに動かない場合(織り込み、悪い利下げ等)を必ず書く。
   チャートは学習用の合成データで、実在銘柄ではないと明記する。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組みとスタイル(淡い背景に丸いカード、上の浮きボタンと下の浮きタブバー。ライト/ダーク対応) |
| `js/app.js` | 画面の切り替え、章ページ、検索、確認問題と間隔反復、ツール(株数計算・期待値) |
| `js/charts.js` | 合成チャートの生成と描画(ローソク足、出来高、移動平均、BB、RSI、MACD) |
| `data/curriculum1〜3.js` | 全8章・50レッスンと確認問題109問。章ページには関連する因果マップ・チャート・人物・重要語をまとめて表示 |
| `data/glossary.js` | 用語集(219語、別名つき) |
| `data/macro.js` | 因果マップ(21の出来事) |
| `data/charts.js` | チャート図鑑(21種類) |
| `data/traders.js` | トレーダー研究(13人)と共通する5原則 |
| `tests/check.js` | データの整合性・検索・計算の確認 |

学習の進み具合はブラウザ(localStorage)にだけ保存されます。ツール画面から書き出し・読み込みができます。

## 確認と内容の追加

```
node learn/tests/check.js
```

レッスンは `data/curriculum*.js` に、用語は `data/glossary.js` に1行足すだけで、検索と本文の用語リンクに反映されます。

## 注意

学習を目的とした教材で、特定の銘柄の売買をすすめるものではありません。税制や制度は変わるため、
実際の手続きは公式情報で確認してください。
