# 株トレ道場

実績ある投資家の原則から、日本株・米国株を基礎から応用まで学ぶための学習アプリです。
ビルド不要の静的サイトで、`learn/index.html` をブラウザで開くだけで動きます
(GitHub Pages では `https://<ユーザー名>.github.io/econobot/learn/`)。

## もとにした依頼と、設計に使ったプロンプト

> 株で高いパフォーマンスを残し副業として成り立たせるために、イチから学べるアプリを作る。
> 米国株・日本株の両方。金利やCPIなどのマクロ、チャートの形、出来高、インジケーターまで。
> 学び方は最適なものを選ぶ。検索機能は必須。一般人の情報ではなく、片山氏・テスタ氏・
> 海外の実績あるトレーダーを参考にする。

これを次の仕様に落として実装しました。

1. **対象と目的**: 本業を持つ初心者が、日本株・米国株で「損小利大を繰り返せる」状態になること。
2. **情報源の基準**: 長年の実績が本人の著書・公表・報道で確認できる投資家(片山晃、テスタ、cis、BNF、
   オニール、ミネルヴィニ、クラマギ、ワインスタイン、リバモア、ドラッケンミラー、P・T・ジョーンズ、
   リンチ、スィコータ)に限り、手法の違いを超えて共通する原則を軸にする。人物ごとに出典を明記し、
   数字は「報じられている」「本人が公表」と区別して書く。
3. **学び方**: 段階別カリキュラム(読む) → 各レッスン末の確認問題(思い出す) → 間隔反復(1→3→7→16→35日)
   → チャート当てクイズとツール(使う)。読み返しより検索練習と分散学習のほうが定着する、という
   学習研究の知見に基づく。
4. **内容**: 株の基礎 / マクロ経済 / 企業分析 / チャート / リスク管理 / 戦略 / メンタルと運用。
   マクロは「起きたこと → 連鎖 → 動きやすい方向 → ただし」の因果マップでも引けるようにする。
5. **検索(必須)**: 用語・レッスン・因果マップ・チャート・人物を横断。別名(消費者物価指数→CPI)、
   全角・ひらがな・小文字の表記ゆれに対応し、関連語をたどれる。
6. **誠実さ**: 利益を保証しない。相場が教科書どおりに動かない場合(織り込み、悪い利下げ等)を必ず書く。
   チャートは学習用の合成データで、実在銘柄ではないと明記する。

## 画面と機能

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | 今日の相場の要約、学習の状況、質問、演習、領域ごとの習熟度、トピック一覧 |
| 今日の相場 | 公的統計(FRED)の指数・金利・為替・VIX・原油・信用スプレッドから「今日の値動きの型」(金利上昇型の下げ、リスクオフ型など)を判定。指数ごとのトレンドの状態、チャート、ニュースの要点、自分の3行メモ |
| 相場の見立て | トレンド・勢いと過熱・恐怖と保険(オプション市場)・信用・金利・流動性・ドルの7つの視点で採点し、短期と中期の見通し(確率の目安)、弱気筋(バーリ・空売り筋)と強気筋の見立て、バーリ流の過熱チェック、シナリオと注目の価格水準、見立てが変わる条件、日本株への影響を表示。AIがプロのアナリストとして詳しく解説(claude.aiで開いた時) |
| チャート演習 | 右側を隠したチャートで、その後の展開・確信度・根拠を答える。学習用の型(19種)と、実際の指数の過去データの2種類。確信度ごとの的中率と、何も考えずに答えた場合の的中率(基準率)を表示 |
| 質問する | 文章で質問すると、関連する教材と今日の相場データを渡してAIが回答(claude.aiで開いた時)。それ以外の環境では教材から関連する解説を表示 |
| ライブラリ | 章ではなく、6つの領域・28のトピックで整理。レベル(基礎・応用・実戦・プロ)で絞り込み |
| 因果マップ / チャート図鑑 / トレーダー研究 / 用語集 / 復習 / ツール | 従来どおり。復習とテストは領域ごとに出題 |

デザインは暗色の丸いカード型。上に丸い浮きボタン(メニュー・復習・検索)、下にガラス風のタブ2つと質問用の丸いボタン。ホームは大きなチャートのカード、ひとことのカード、領域ごとに横に流れる小さなタイルの棚で構成します。

## 実データの流れ

毎朝8時(日本時間)に動く `econobot.py` が、ニュースの配信の後に FRED から次の系列を取得し、`learn/data/market.json` として main ブランチに書き出します。アプリはこのファイルを読みます(取得できない日も、ニュースの配信は止めません)。

S&P 500、ナスダック総合、ダウ平均、日経平均、ドル円(以上は約10年分)、米10年・2年金利、10年−2年金利差、VIX、WTI原油、米ハイイールド債スプレッド、3か月VIX、シカゴ連銀 金融環境指数、FRBの総資産、ドル指数(約2年分)

### 深掘り分析(`learn/data/analysis.json`)
同じく投稿の後に `deep_dive.py` が動き、「なぜ動いたか」の画面のデータを書き出します。
1. Yahoo Finance から米国12セクター・日本17業種(TOPIX-17のETF)・世界の指数・金利・商品・信用を取得
2. 騰落を「ふだんの値動きの何倍か(z値)」にそろえ、資金の流れ(景気敏感とディフェンシブ、半導体、相場の幅、外需と内需など10本)を計算
   - 正確さの確認: 騰落は配当を調整した値、水準は実際の終値。分割の調整の誤り(前後の中央値の半分未満・2倍超)は捨てる。
     原油・金・銅・ドル指数は取引のセッションで日付を付け、取引中の値は使わない。ドル円は米東部17時、ビットコインは米国株の引けの値。
     NYSEの休日を入れた「その日あるべき取引日」と照らし、遅れた銘柄は約7分かけて取り直す。SPYとS&P 500指数、10年債と米国財務省の値を照合する。
     投稿の後の予備の起動(8:10)で、データが欠けていたら作り直す
   - 指数を動かした銘柄: 日米の主力10銘柄ずつで、日経平均−TOPIX、時価総額加重−均等加重の差を推定の寄与に分ける(重みは前日までの約1年から推定)
   - その日に大きく動いた大型株: Yahooのスクリーナーから、時価総額500億ドル以上で当日の値のものだけ(決算の前後かも付ける)
   - 銘柄の構成は、過去1年の実データで「セクターだけ」「主力銘柄を加える」「その日の上位を加える」の説明力を比べて決めた(deep_dive.py の 2b 節)
3. 規則にもとづく主因の候補を作る(AIが使えない日も表示される)
4. Gemini で役割の違うアナリストを順に重ねる: マクロ・金利 → セクター・資金 → 世界情勢・ニュース → 弱気筋 → 強気筋 → チーフの統合 → 査読 → 指摘があれば改訂
5. AIの文章の数字を、単位ごとにデータとニュースに照合し、確かめられない数字を含む文は捨てる
6. 見立てを履歴に残し、5営業日後の値動きで答え合わせする

### 需給と戦略(`flows.py`、analysis.json の flow と strategy)
- 出来高: S&P 500・ナスダック・日経平均の売り抜けの日(25日)とフォロースルー(オニール)
- オプション: CBOEのプット・コール比率(履歴を残す)、VIX9日・VIX・VIX3か月の期間構造、VVIX・SKEW・ナスダックのVIX
- 大口の持ち高: CFTCの金融先物の建玉(S&P 500・ナスダック100・日経平均・円・米10年債)、過去3年での偏り
- 日本: JPXの投資部門別売買状況(東証プライム)と信用取引現在高(毎週、履歴を残す)
- 需給の日程: 米国のオプションの満期、日本のSQ、月末・四半期末
- 戦略: 投資比率は「月末の終値が200日平均の上なら投資、下なら待機」。過去20年で、トレンド・売り抜けの日・VIXを組み合わせた
  毎日の規則より安定し、最大の下落を約半分にした(検証の結果は flows.py の6節)。売り抜けの日・VIXなどは「注意の度合い」として、
  1回の売買の大きさの目安に使う。ATR・移動平均・高値と安値の価格帯も出す
- AIの役割に「需給・ポジション」と「売買戦略とリスク管理」を加え、チーフが需給の結論と戦い方をまとめる

claude.ai に公開している版(Artifact)は外部のデータを読めないため、自動では更新されません。必要な時に `learn/tools/refresh_artifact.py` でページとデータを書き出し、公開し直します。

ファイルが無い間は、「今日の相場」と実データの演習は説明の表示に切り替わります。

## 知識を定着させる仕組み

読んだ量ではなく「覚えていて、使える量」を増やすための設計です。

- **3つのレベル**: 基礎 → 応用(一段深い知識) → 実戦(売買の手順)。章ページで分けて表示
- **4種類の問題を同じ間隔反復に乗せる**: 確認問題(260問)、ケース演習(22問)、用語カード(219語)、チャート当て
- **章末テスト**: 章の問題とケースから10問、8問以上で合格
- **習熟マップ**: 章ごとに「修了(読んだ)」と「定着(復習で正解を重ねた)」を分けて表示

## 確認と内容の追加

```
node learn/tests/check.js
```

レッスンは `data/curriculum*.js` に、用語は `data/glossary.js` に1行足すだけで、検索と本文の用語リンクに反映されます。
