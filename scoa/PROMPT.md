# SCOA-A 学習アプリ 開発プロンプト

このファイルは、依頼内容から起こした開発用プロンプト(仕様書)です。`scoa/` 配下のアプリはこの内容に沿って実装しています。

---

## 役割

あなたはスマホ向け学習アプリの開発者 兼 就職・公務員試験(SCOA)の問題作成者です。
SCOA-A(基礎能力検査)の対策を、スマホ1台だけで完結できるWebアプリを作ってください。

## 前提:SCOA-A の出題傾向(調査結果)

- 5分野 計120問を60分で解く(1問あたり約30秒)。五肢択一。難度は中学〜高校基礎だが範囲が広く、速さが問われる。
- 参考書等で一般的とされる配分:言語20 / 数理25 / 論理25 / 常識25 / 英語25。
- 分野ごとの頻出内容
  - **言語**:同義語・対義語、四字熟語、ことわざ・慣用句、漢字の読み、同音異義語、敬語、文法、語句の意味、文学史
  - **数理**:四則演算、四則逆算、分数、方程式(一次・連立・二次)、不等式、数列、割合・損益、速さ、濃度、仕事算、確率、場合の数、図形、数の大小、n進法、約数・倍数、年齢算、平均、比、平方根、式の展開
  - **論理**:命題(対偶・三段論法)、順序・順位、対応関係、うそつき問題、集合、サイコロ、展開図、暗号・規則性、曜日、魔方陣、方位、試合数など
  - **常識**:社会(日本史・世界史・地理・政治・経済・国際/時事)、理科(物理・化学・生物・地学)
  - **英語**:同意語・反意語、空欄補充(文法)、熟語、発音・アクセント、英語のことわざ、会話文、語形変化
- 時事は、変わりやすい「現職者名」などは避け、制度・年号・国際機関など確定した事実で出題する。

## 必須要件

1. **スマホ完結**:インストール不要。ブラウザで開くだけで動く。片手操作しやすい大きなタップ領域、下部タブ。ライト/ダーク両対応。
2. **教科別に学習**:5教科を個別に選べる。さらに教科内の小分野も選べる。
3. **全問に解答と解説**:回答直後に正誤・正解・解説を表示する。
4. **日ごとの履歴**:解いた問題は必ず日付ごとに記録する(問題・自分の回答・正誤・解説)。
5. **履歴から復習**:日ごとの履歴を開き、「その日の全問」「その日の間違いだけ」を解き直せる。全期間の「苦手問題(直近で間違えた問題)」も教科別に解き直せる。
6. **網羅性**:上記の頻出内容をすべてカバーする。知識問題は固定の問題集、計算・推論問題は数値を変えて自動生成し、何度でも新しい問題で練習できるようにする(自動生成問題にも途中式つきの解説を付ける)。
7. **本番形式**:120問・60分の模擬試験モード(配分は上記)。終了後に全問の解答・解説を確認できる。
8. **データ保存**:履歴は端末に保存。バックアップの書き出し/読み込みと全消去ができる。

## 設計方針

- 構成:`index.html`(画面とスタイル)、`questions.js`(固定問題)、`gen.js`(自動生成問題)、`app.js`(動作)。ビルド不要・外部ライブラリなし。
- 問題データは「正解を選択肢の先頭に書く」形式で持ち、表示時にシャッフルする(データの誤りを防ぐため)。
- 出題順は「未出題を優先 / 苦手を優先 / ランダム」から選べる。
- 練習モードでは任意で「本番ペース(1問30秒)」のタイマーを付けられる。
- 履歴1件 = 日時・教科・小分野・問題ID(自動生成問題は問題文ごと保存)・選んだ選択肢・正誤。

## 完了条件

- 5教科すべてで出題→回答→解説表示→履歴保存→履歴からの解き直しが動く。
- 自動生成問題を大量に生成しても、選択肢の重複や正解の欠落がない(検証スクリプトで確認)。
- スマホ幅(約400px)で横スクロールが出ない。
